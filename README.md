# SQL-тренажёр для ИТ-аудита

Личное веб-приложение для тренировки SQL на вымышленных данных ИТ-аудита. Исходное задание описано в [project_idea.md](project_idea.md), набор из 12 заданий – в [docs/tasks.md](docs/tasks.md), план разработки – в [docs/plan.md](docs/plan.md).

## Стек

- Vite – сборка и локальный сервер разработки.
- React и TypeScript – интерфейс и типизированная логика.
- CodeMirror 6 (`@uiw/react-codemirror`, `@codemirror/lang-sql`) – редактор SQL с подсветкой синтаксиса SQLite.
- sql.js (SQLite в WebAssembly) – учебная база и выполнение запросов в браузере.
- Web Worker – выполнение SQL вне основного потока страницы; на каждое выполнение создаётся база с исходными данными.
- localStorage – локальное хранение последнего запроса; далее здесь же будет храниться прогресс.
- Git – история изменений. Сервер и подключение к реальным данным не требуются.

Версии зависимостей зафиксированы в `package-lock.json`.

## Запуск

Нужен Node.js, совместимый с установленной версией Vite.

```bash
npm ci
npm run dev
```

Проверка сборки:

```bash
npm test
npm run build
npm run preview
```

## Состояние проекта

После второй итерации доступны каталог и задания 1–6. Можно перейти между заданиями, видеть условие и схему таблиц, просмотреть первые строки любой таблицы рядом с редактором, выполнить SQL и получить результат или сообщение об ошибке. Вымышленная база восстанавливается перед каждым запуском. Последний запрос сохраняется отдельно для каждого задания. Проверка ответа, подсказки и прогресс будут добавлены в следующих итерациях.

Для проверки ответов планируется сравнивать строки результата с ожидаемыми строками с учётом повторов; порядок строк учитывать только там, где он явно требуется условием. Текст SQL не служит критерием проверки.
